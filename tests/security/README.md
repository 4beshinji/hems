# tests/security/

Security regression tests for HEMS.  Two categories:

## 1. Pytest tests (CI-runnable)

| File | Marker | Requires | Description |
|------|--------|----------|-------------|
| `test_unauth_coverage.py` | *(none)* | TestClient only | Walks every backend route and asserts 401 when `BACKEND_API_KEY` is set. Catches unprotected dashboard endpoints. |
| `test_device_id_injection.py` | *(none)* | brain src importable | MQTT auto-registration path: injected `device_id` (path traversal, wildcards, null bytes) must not pass `is_valid_device_ref()` and must not be forwarded to the backend heartbeat. |
| `test_mqtt_acl.py` | `integration` | Live Mosquitto broker | Verifies that each service user is denied publish on topics outside its ACL. Skips automatically when the broker is unreachable. |

### Running the non-integration tests (default CI gate)

```bash
PYTHONPATH=services/brain/src:services/backend \
  pytest tests/security/test_unauth_coverage.py tests/security/test_device_id_injection.py -v
```

Or as part of the full suite:

```bash
PYTHONPATH=services/brain/src:services/backend \
  pytest tests/ services/brain/tests/ -q -m "not integration and not e2e and not benchmark"
```

### Running the integration tests (requires Docker Compose)

Start the HEMS stack first:

```bash
cd infra && docker compose up -d mosquitto
```

Then run with the `integration` marker:

```bash
PYTHONPATH=services/brain/src:services/backend \
  pytest tests/security/test_mqtt_acl.py -m integration -v
```

Passwords for test MQTT users are read from environment variables
`MQTT_PASS_<SERVICE>` (e.g. `MQTT_PASS_BRAIN`).  Defaults match the
development passwords generated by `infra/mosquitto/setup-users.sh`.

## 2. Shell / HTML PoCs (manual)

Legacy proof-of-concept scripts used during initial hardening audits.
Run via `tests/security/run_all_pocs.sh`.

| File | Scenario |
|------|----------|
| `poc_unauth_api.sh` | V7: API accessibility (LAN-trusted, auth-off) |
| `poc_mqtt_acl.sh` | V1: MQTT broker reachability check |
| `poc_prompt_injection.py` | V2: Malicious payloads via MQTT (manual brain log review) |
| `poc_command_bypass.py` | V3: Command allowlist bypass (unit, no service needed) |
| `poc_path_traversal.py` | V4: Path traversal in device IDs (unit) |
| `poc_biometric_spoof.sh` | V5: Biometric endpoint spoofing |
| `poc_cors_csrf.html` | V6: CORS/CSRF (manual browser test) |
| `poc_ha_params.py` | V8: HA params injection (unit) |

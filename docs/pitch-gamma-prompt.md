# Gamma.app / AI プレゼン生成ツール用プロンプト

以下のテキストをそのままGamma.app等のAIプレゼン生成ツールに貼り付けて使用する。

---

## 貼り付け用テキスト

タイトル: HEMS — 三空間統合型パーソナル AI 基盤

スライド1 タイトル:
HEMS — Home Environment Management System
三空間統合型パーソナル AI 基盤
実空間・個人電子空間・インターネットを1つの認知エンジンに統合する

スライド2 問題提起:
スマートホームは「部屋」しか見ない。AIアシスタントは「会話」しかできない。PC監視ツールは「マシン」しか知らない。これらは別々のアプリで互いに情報を共有しない。生活は1つなのにツールはバラバラ。

スライド3 HEMSの回答:
実空間・個人電子空間・インターネットの3空間を1つの認知エンジンに統合。30秒サイクルの自律判断ループが、聞かれなくても三空間を走査し、判断し、行動する。

スライド4 三空間の構成:
実空間: 温湿度/CO2/VOC、気圧/照度、赤外線PIR、24GHzミリ波レーダー、カメラ(YOLO+VLM)、スマートホーム状態、心拍/SpO2/HRV、睡眠/ストレス/疲労
個人電子空間: PC CPU/GPU/メモリ、プロセス監視、ブラウザ状態、Obsidian vault、スクリーンタイム、買い物リスト
インターネット: Google Calendar、Gmail未読、GitHub通知、RSSニュース、天気予報(JMA)

スライド5 センサースタック（6モダリティで死角を潰す）:
環境センサー(BME680, MH-Z19) → 空気質・気圧変動
赤外線PIR → 動体検知
24GHz mmWave → 存在+微動(呼吸)
YOLOv11s-pose → 人数・姿勢・骨格
VLM(moondream/minicpm-v) → シーン理解・状況記述
スマートバンド → 心拍/睡眠/ストレス/疲労

スライド6 VLMの役割（センサーが取れない文脈を言語で補完）:
PIR+mmWave → 「誰かがソファにいる」
YOLO → 「1人、臥位」
VLM → 「横臥状態。照明点灯中。リモコン落下」
→ Brainの判断が「臥位」から「寝落ちの可能性が高い」に変わる
適応的頻度制御: 通常30分→イベント時1-5分→無人時2時間
GPU協調: VLM推論中はBrain LLMを退避しルールエンジンにフォールバック

スライド7 デモ: 三空間の複合判断:
14:30 実空間CO2 1200ppm+室温28°C、YOLO座位2時間継続、電子空間GPU 95%、生体心拍95bpm
→ Brain ReAct: CO2高+暑+長時間座位+心拍上昇+GPU排熱 → 冷房強化+休憩促進
→ Action: control_climate(cool, 25°C) + speak(休憩推奨)

スライド8 デモ: VLMによるセンサー補完:
23:45 PIR反応なし、mmWave存在あり(呼吸)、YOLO臥位、VLM「横臥・照明点灯・リモコン落下」、心拍58bpm低下傾向
→ Brain: 寝落ちと判断 → 消灯+小音量通知

スライド9 デモ: インターネット連携:
07:00 生体で睡眠終了検知→wake_upイベント
ニュース要約取得、天気午後降雨、GitHub PR 3件
→ イベント自動化: 天気+ニュース+未読通知を音声一括通知

スライド10 既存アプローチとの比較:
ローカルLLM: 認知範囲なし、自律判断なし → HEMSの脳の一部
opencraw: PC1台のみ、閾値アラート → HEMSのデジタル空間の一部
AI秘書: 音声のみ、クラウド、受動的 → HEMSは完全ローカル+三空間+能動的

スライド11 ポジショニングマップ:
縦軸: 自律性（聞かれなくても行動する）
横軸: 認知範囲（PCのみ→部屋→三空間統合）
ローカルLLM(低・狭)、opencraw(低・PC)、Home Assistant(中・部屋)、AI秘書(低・狭)、HEMS(高・三空間)

スライド12 数字:
統合空間3、マイクロサービス18、Brainツール33、センサーモダリティ6、認知ループ30秒、LLMプロバイダー3、データ保持730日、起動コマンド1

スライド13 段階的導入:
Step1(5分): cp env.example .env && docker compose up
Step2: +ローカルLLM (--profile ollama)
Step3: +スマートホーム+生体+カメラ+ニュース (--profile ha biometric perception news ollama)
